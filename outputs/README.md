# Generated outputs

These are the seeded outputs underlying the four numerical tables and Figure 1
in Section 6. They report exact pathwise simulations under positive premium
loadings 0.10, 0.20, and 0.50 and are committed intentionally so readers can inspect
the reported values without rerunning the full simulation. Both models use
10,000,000 paths.

Running the following command from the parent directory regenerates and overwrites these files:

```sh
Rscript code/NumExp_Sec6.R outputs
```

Use a separate output directory for quick tests or altered simulation settings.
